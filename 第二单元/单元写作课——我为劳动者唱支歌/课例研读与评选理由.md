## 二、教学设计的思路亮点

### 亮点一：两次"咬文嚼字"，把"要求"拆成可执行的动作

两个任务的要求都只有八个字（"中心明确，描写生动"／"感情真挚，富有文采"），但教案把题目本身拆开了：

**描写任务的六个关键词：**

| 词 | 操作定义 |
|---|---|
| 展开联想 | 联想需合理，从日常生活、**文学创作、影视剧**等题材生发 |
| 一个人或一群人 | 描写主体需突出，可以是个人，也可以是**群体的场面** |
| 个人 | **重点突出，描写手法多样** |
| 群体 | **点面结合，详略得当** |
| 劳动 | 描写的主题 |
| 情景 | 有"**情**"有"**景**"，**景象中需蕴含感情** |

**抒情任务的四个关键词：**

| 词 | 操作定义 |
|---|---|
| 我 | 抒情主人公（**可显可隐**） |
| 劳动者 | 抒情对象（**可点可面**） |
| 唱支歌 | **抒情、吟咏的导向** |
| 小诗 | 形式：押韵、对偶、排比、反复；内容：精炼的语言描写、抒情、议论（**以抒情为主**），**运用意象** |

**"可显可隐""可点可面"这两条尤其有价值**——它们直接回答了学生最常犯的两种犹疑：写诗要不要出现"我"？要不要写具体某个人？**答案是不必，两种都可以。** 这类"允许范围"的说明，比"要感情真挚"有用得多。

### 亮点二：六则描写例文，构成一个"劳动类型谱系"

六则例文的对象分别是：

| 例文 | 对象 | 劳动类型 |
|---|---|---|
| 一 | 建筑工地工人 | **体力劳动**（重体力） |
| 二 | 故宫文物修复师 | **技艺型劳动**（修复） |
| 三 | 软件工程师 | **脑力劳动**（编程） |
| 四 | 摩天大楼"蜘蛛人" | **高危体力劳动** |
| 五 | 煎饼摊主 | **个体经营·手艺** |
| 六 | 翻译者 | **知识劳动**（学术） |

**这六个对象是精心配的。** 学生写"劳动者"，十个里有八个写环卫工人或老师；这六则例文摆出来，**"劳动者"这个词的覆盖面立刻被撑开**。

而且例文二的评析顺势把"劳动"分了三层——

> **简单含义**——洒水、扫地、大扫除……
> **深层含义**——可以是体力劳动也可以是脑力劳动。
> **复杂含义**——**创造性劳动**……
> "这个写作任务就像是以'劳动'为主题**搭建舞台**，同学们可以**做广播体操、跳国标舞，也可以跳民族舞、芭蕾舞**。"

**"搭舞台"这个比喻解决了"选材雷同"这个写作课的老问题**：题目不是限制，是舞台；舞台上的节目可以完全不同。这比"要选择有代表性的劳动者"有效得多——**因为它把"选材"从"挑选正确对象"改成了"设计自己的节目"**。

### 亮点三：例文一的评析，给了"典型性"一个反面定义

例文一（建筑工地工人）的评析是本课最诚实的一段：

> 能感受到小作者有着**强烈的要写好的愿望**。首先是内容是切题的……**有点可惜的是，描写稍显简单了点；几个细节放在其他劳动者身上，好像也可以**；而且最后升华主题的地方，**有些牵强，描写没有到位，一下子在主题上拔得太高，容易在情感表达上失真**。

**"几个细节放在其他劳动者身上，好像也可以"——这句话就是"典型性"的反面定义。**

它比任何正面定义都清楚：一个细节是否典型，检验办法就是"能不能换个人"。这与本单元《我为劳动者绘风采（一）》（TB015）里那张"可替换性测试表"（运送物品／时代背景／运送时间／服务对象／其他人物换成别的行不行）**是同一条标准的两种说法**——一个用文字说，一个用表格做。

而"主题上拔得太高，容易在情感表达上失真"也点出了学生写作的通病：**结尾强行升华**。这两句评语合起来，**比一整节"如何进行细节描写"的课更管用**。

### 亮点四：六则抒情例文，兑现了"体裁不限"

任务写的是"**诗歌体裁不限，可以是古体诗，也可以是现代诗**"。多数课例说完这句就只给一种范文，本课**真的给了六种**：

| 例文 | 体裁 | 形式特征 |
|---|---|---|
| 一 | **诗经体四言** | 四言、句末"兮"、重章 |
| 二 | **古体七言** | 五七言交替、一韵到底 |
| 三 | **现代诗·排比** | "我看见……我看见……我想唱……"三段递进 |
| 四 | **分行排比** | 斜线分行、"阡陌之间／手术台前／三尺案边"三个场景 |
| 五 | **散文诗** | 无固定行数、引《诗经》句作骨 |
| 六 | **数字入诗** | "一二言语…三四人的生活…五六个老茧…七八点星天外…九十点的雨山前…百千点尘土…万份尊敬" |

**例文六是全批 16 个课例中最特别的一份范文。** 用数字串起一个人的一天与一生（一二人、三四人、五六个茧、七八点到九十点、百千点尘土、万份尊敬），**这是一种游戏性的写法，但效果极好**——教师评"数字入诗，饶有意昧"，四个字点到为止，不解释。

**"体裁不限"被真的执行了**，这件事本身比十二则例文更有价值：学生看到"我可以这样写"，而不是"我必须写成例文一那样"。

### 亮点五：教师用韵文写评语

六则抒情例文的评语，有两条本身就是韵文：

> 例文一："**诗经为体，劳动为题。文质兼美，令人称奇。此等答案，多多为宜。**"
> 例文二："**青青园中葵，乐府入诗题。五七言更替，韵齐味亦奇。古来香山叹刈麦，今有考生颂勤劳。**"

**这是很小但很妙的一处设计。** 学生在学写诗，教师的评语也是诗——**评语本身就在示范"什么叫文采"**。而且"古来香山叹刈麦"（白居易《观刈麦》）把例文二接回了古诗传统，"今有考生颂勤劳"又把学生放了进去。**一行评语里完成了古今对接。**

### 亮点六：两处高考真题，一近一远

环节三补 **2020 年高考北京卷微写作**（"生活技能大赛"——展示烹饪、插花、做手工、修器具等技能，介绍一项自己擅长的生活技能，语言简明、条理清楚），并接《中小学生守则》第三条"**勤劳笃行乐奉献。自己事自己做，主动分担家务，参与劳动实践，热心志愿服务**"。

环节五补 **2019 年高考全国 I 卷**（"民生在勤，勤则不匮"演讲稿，不少于 800 字）。

**两道题的分工很清楚**：

- 2020 北京卷微写作 → 接**"生活技能"**，与"描写"任务同属**具体、可操作**的一路；
- 2019 全国 I 卷大作文 → 接**"劳动的意义"**，与"抒情"任务同属**认识、说理**的一路。

**一近一远、一小一大、一技一理。** 而且 2020 北京卷那道题（"介绍一项自己擅长的生活技能"）恰好可以检验学生能不能把"描写"用在**自己会做的事**上——这是本课"把视角转向自己的生活"那句话的落地。

### 亮点七：一条完整的证据链——高考题、起始课问卷、单元写作课

这是本课在整册 16 个课例中最独特的一处发现。

**2019 年高考全国 I 卷作文材料原文**（本课第 26 页课件整页呈现）：

> 有的说："我们学习这么忙，劳动太占时间了！"有的说："**科技进步这么快，劳动的事，以后可以交给人工智能啊！**"也有的说："**劳动这么苦，这么累，干吗非得自己干？花点钱让别人去做好了！**"

**本单元起始课（TB009）课前问卷第 5 题**：

> 有人说"**我可以花钱雇人劳动**"，也有人说"**AI 技术可以替代我劳动**"，那今天提倡劳动还有意义吗？为什么？

**两相对照，"花钱雇人"与"花点钱让别人去做好"、"AI 替代劳动"与"交给人工智能"，几乎是逐句改写。**

结论很清楚：**起始课问卷第 5 题是把 2019 全国 I 卷作文材料改写成了一道课前问卷。** 而本课（单元写作课）又把原题完整端出来，作为写作的思想背景。

**这条链条是这样的：**

```
2019 全国 I 卷（原题）
   ↓ 改写成两道选择题式问句
起始课课前问卷第 5 题（口头回答）
   ↓ 单元学习（三篇通讯、两首古诗、一篇评论）
本课环节五（原题重现）＋ 结语"热爱劳动，从我做起"
```

**它解释了一个之前不好解释的问题**：起始课那道问卷题为什么问得那么锋利？因为它本来就是一道高考题。**教师是把高考题的争点，提前变成了学生的自我诊断。**

### 亮点八：导入明确交代"起始课的两项写作已经完成"

导入有这样一句：

> "在单元系列写作活动中，讲授老师为大家布置了这样两个练习：① **记者穿越到古代写报道**；② **为一位劳模写一首小诗**。**相信同学们在前面的学习中，这两个任务都已经完成得很不错了**，那么今天我们就站在这个基础上，往前推进一步。"

**这是第二单元"写作闭环"的书面证据。** 起始课第五环节布置了四项写作，本课明确说前两项（① 古代记者报道、② 为劳模写诗）**已经完成**，并把本课的落点推到第 ④ 项（写身边的普通劳动者）。

对照已研读的课例：
- ① 古代记者报道 → 《芣苢》《插秧歌》（TB010）课后练习第 2 题（一字不差）
- ② 为劳模写诗 → **本课确认已完成**
- ③ 工匠精神新闻短评 → 《以工匠精神雕琢时代品质》（TB013）作业（一字不差）
- ④ 凡人微光记叙文 → 《我为劳动者绘风采（一）》（TB015）导入布置

**四项全部有下落。** 这是第二单元第四种闭环机制（问题闭环、作业闭环、导图闭环之外，再加**写作闭环**）。

### 亮点九：单元导图第三次原样出现

导入的完整版单元导图（学习内容／学习目标／单元学习任务三分支），与起始课（TB009）第六环节的小结图、《以工匠精神雕琢时代品质》（TB013）第 28 页的完成版**同源**。

一处细节值得注意：本课导图把"单元学习任务"明确写成"**提高认识**＝如何全面深刻地认识劳动——**完成思维导图**；**学会表达**＝新闻和评论的独特表达——**完成习作**"。

**"思维导图"与"习作"被并列为两类产物**——一张图管"认识"，一篇文管"表达"。**这解释了这个单元为什么既有导图又有四项写作：它们不是两种活动，是一件事的两面。**（这一点与第一单元"九列总表只被回填一次"形成鲜明对照。）

## 三、对照专家标准的评选理由

### 3.1 四维指标

| 维度 | 标准（学生视角） | 本课证据 | 判定 |
|---|---|---|---|
| **目标内容**<br>学生学什么 | 目标科学具体、内容层层递进 | 五条目标分人文／语文两组，**语文素养第（2）条写得极细**——"形式上能注意到押韵、对偶等诗歌特点，能较好地使用排比、反复等诗歌创作手法；内容上能以精炼的语言描写、抒情，会运用意象进行创作"，**把"写诗"拆成了形式与内容两套要求**，是全批 16 课里语文目标最细的一条。不足：难点定在人文素养（1）（"加深对劳动者意义和价值的认识"），**这是认识层面的目标，却作为教学难点**，难以在写作课内检验 | 良＋ |
| **教学过程**<br>学生怎么学会 | 是否真正把学生放在中心 | 两次"咬文嚼字"拆题是实的（六词＋四词）；"任选一个任务写 150 字"也是实的。但**学生活动只有两处**：选一个任务写、按关键词评例文；且**教案没有记录学生怎么评、评出了什么**——十二则例文的评析全部由教师给出 | 良 |
| **教学资源**<br>我准备了什么 | 资源是否真的支撑学生学 | **例文数量全批最多（12 则）**，且六则描写覆盖六种劳动类型、六则抒情覆盖六种诗体；另有 2020 北京卷微写作、2019 全国 I 卷（原文整页）、完整版单元导图、《中小学生守则》第三条。**资源密度是全册最高的一处**；但十二则例文对一课时偏多（见 3.4） | 优 |
| **技术规范**<br>学生看得清不清楚 | 呈现是否清楚、稳定 | 28 页；**例文一页一则**（不挤）、**评语用红字**（与例文正文分开）、高考真题整页呈现（不打散）；第 26 页 2019 全国 I 卷全题一字不删。不足：28 页对应 12 则例文＋多个步骤页，页数偏多；导入的单元导图页字号偏小 | 良＋ |

### 3.2 好课四特征

**① 理念清晰**：一句话——"**把'写 150 字'这件事拆成两步：先读懂题目里的每一个词，再看十二份别人怎么写——描写的六份、抒情的六份。**"读懂题在前，看样例在后，顺序对了。

**② 思维流畅**：回指起始课 → 单元导图三分支 → 说明起始课两项写作已完成 → 呈现两个小任务 → 描写任务咬文嚼字（六词）→ 六则例文 → 小结四句（中心突出／描写生动／选材丰富／见识独到）→ 2020 北京卷 → 抒情任务咬文嚼字（四词）→ 六则例文 → 2019 全国 I 卷 → 结语。

**结构是"任务—拆题—例文"重复两次**，与任务的两个分支（描写／抒情）严格对应。**清楚，但两次循环之间没有递进**——描写与抒情是并列的两种表达方式，不是由浅入深。

**③ 学生主体**：◐。有"任选一任务写 150 字"和"按关键词评例文"两处动作，但**教案里看不到一句学生的评析结果**——十二则例文的评语全是教师的。**学生在本课是"读者"多、"作者"少。**

**④ 实践创新**：✅✅ 两处半。**"咬文嚼字"把题目拆成六词／四词的操作定义**（"我"可显可隐、"劳动者"可点可面）；**十二则例文构成劳动类型谱系与诗体谱系**（"以'劳动'为主题搭建舞台，可以做广播体操，也可以跳芭蕾舞"）；半处是**用韵文写评语**（"诗经为体，劳动为题"）。

### 3.3 四大支柱与素养锚定

| 项 | 判断与依据 |
|---|---|
| 理念为基 | ✅ 描写与抒情两种表达方式的分工，"生活是创作源泉"，"把视角转向自己的生活"——三个判断都落到了任务上 |
| 目标为纲 | ◐ 目标细，但**作业只有一句"完成自己的微写作任务"**，没有标准、没有评分、没有互批；两处高考真题只作"教师补充"，**未纳入任何评价环节** |
| 实施为重 | ⚠️ **本课教案没有时间标注**（"时间"列全空）。从内容量看（12 则例文＋两次拆题＋两处高考真题＋单元导图），一课时几乎不可能完成；与周明鉴版（标注 25 分钟）、绘风采一（23 分钟）、绘风采二（23 分钟）相比，这一份干脆回避了时间问题 |
| 个性为魂 | ✅ "以'劳动'为主题搭建舞台……可以跳民族舞、芭蕾舞"这个比喻有个人风格；韵文评语也有 |
| **目标精准可测** | ◐ 150 字是硬指标，可测；但"中心明确、描写生动""感情真挚、富有文采"**无任何尺度**，且没有评分表（对照《芣苢》董晓版有五维 50 分量表） |
| **思维方法建构** | ✅✅ 三样：**关键词拆解法**（把题目当文本读，逐词给操作定义）、**例文评析法**（按题目关键词去评例文，而非凭感觉）、**劳动类型三层谱系**（简单／深层／复杂含义） |
| **单元整体视角** | ✅✅ 强。导入回指起始课并**原样复现完整版单元导图**（第三次出现）；**明确写出起始课两项写作"已经完成"**，把本课定位为第 ④ 项的起点；作业接续"凡人微光"。**四项写作在此全部有了下落** |
| **问题链驱动** | ◐ 感知（题目要求什么）→ 分析（例文好在哪里、差在哪里）→ 创造（写 150 字）。三级都有，但**"分析"环节的结论由教师给出**，学生的分析没有进入课堂记录 |

### 3.4 需要说出的五处问题

1. **本课没有时间标注**。教案"时间"列全空——这在已研读的 10 份有"时间"列的 2020 批课例中是唯一的。**从内容量看，12 则例文＋两次拆题＋两处高考真题＋单元导图，一课时无法完成**；而同一单元的其他三课（周明鉴 25 分钟、绘风采一 23 分钟、绘风采二 23 分钟）都标注了——**这一份的空白，更像是无法给出一个合理数字。**
2. **作业只有一句话**。"请同学们梳理、总结课堂学习的内容，完成自己的微写作任务。"——**无字数（正文有 150 字，但作业页没写）、无标准、无评分、无互批**。对照《芣苢》董晓版作业有五维用量表＋同桌互批，本课的作业页是全册最薄的一页。
3. **"不超过 150 字"与例文长度不匹配**。任务明确"不超过 150 字"，但抒情例文五（散文诗）、例文六（数字诗）都明显超过 150 字（例文六约 160 字）。**范文比要求长，学生会误判篇幅**——这类细节在写作课上影响不小。
4. **两处高考真题只作"教师补充"，没有变成任务**。环节三补 2020 北京卷，环节五补 2019 全国 I 卷，两次都是"教师补充 ×× 高考题"＋"教师启发同学们思考……"，然后直接进入下一环节。**材料极好，用法却是"展示"而非"使用"**：为什么不让学用刚学的六条关键词去评这道高考题该怎么写？为什么不让学生看 2019 那道题里"AI 替代劳动"的说法，与自己起始课问卷的答案对一对？**这是本课最可惜的地方。**
5. **"讲授老师"的自称混乱**。教案多处写"在单元起始课上，**讲授老师**带着大家梳理了本单元的学习内容""在单元系列写作活动中，**讲授老师**为大家布置了这样两个练习"。这是教师**口播稿**直接抄进教案的结果——"讲授老师"指自己，但写成第三人称，读起来像在指别人。同类表述在本单元（绘风采一"起始课时**倪老师**提到的写作任务"）中也有，但那里倪莉确实是起始课教师，此处则不通。

### 3.5 一句话评选理由

> 这节课把“写一百五十字”拆成“读题—看样例”两步：先回指起始课、原样复现完整版单元导图并交代“记者穿越古代写报道”“为劳模写一首小诗”两项已完成，再呈现描写与抒情两个小任务供学生任选其一，随后用六个关键词拆描写题、配六则例文（工地、故宫修复师、程序员、蜘蛛人、煎饼摊、翻译者），末了用四个关键词拆抒情题、再配六则诗经体、七言、现代诗、分行排比、散文诗、数字诗，两处高考真题夹在中间作补充；最亮的是例文一的评析，它给“典型性”一个反面定义——“几个细节放在其他劳动者身上，好像也可以”，后半句“在主题上拔得太高，容易在情感表达上失真”又点出结尾强行升华的通病，一节细节描写课也不过如此；问题在于教案“时间”列全空、十二则例文加两次拆题加两处真题一课时无法完成，作业只有“完成自己的微写作任务”一句、无标准无评分无互批，任务写“不超过150字”而抒情例文五、六明显超长、范文比要求长，2020北京卷与2019全国I卷都只作“教师补充”、材料极好却只用于展示未变成任务，教案多处“讲授老师”第三人称自称、系口播稿直接抄入所致。
