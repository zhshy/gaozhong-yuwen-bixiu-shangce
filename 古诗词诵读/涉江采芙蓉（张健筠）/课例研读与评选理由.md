## 二、教学设计的思路亮点

### 亮点一：四栏表里"学生活动"是独立一栏，不是"教师活动"的附注

这一份教案的排版值得单说。教案第 2、3 页是一张**四栏表**：

> 教学环节｜教师活动｜**学生活动**｜设计意图

七行七填，**"学生活动"一栏每一行都有字**，而且写的是**具体动作**：

| 环节 | 学生活动（原文） |
|---|---|
| 课堂导入 | "课前自学《涉江采芙蓉》并**收集《古诗十九首》的相关资料**" |
| 知人论世 | "**听音频朗诵，纠正读音，留意注释**，进一步体悟诗歌情感" |
| 任务一 | "**对比分析、个人发言**" |
| 任务二 | "**思考、分析、个人发言**" |
| 任务三 | "**诵读，小组交流讨论，小组代表发言**" |
| 总结方法 | "**理解、识记**" |
| 布置作业 | "完成作业，**全班课后交流展示，优秀作品张贴在班级宣传栏**" |

**这张表最大的价值，是它把"学生做什么"逼到了台面上。** 填"任务一→对比分析、个人发言"时，教师必须回答"学生到底做什么动作"；而大多数教案写到这里只写"教师提问，学生回答"。**这五个字（对比、分析、发言）已经是本组五份资源里对"学生行为"最不含糊的表述。**

而且它同时暴露了短板：**"总结方法"一栏填的是"理解、识记"，"布置作业"一栏填的是"完成作业"**——这两处不是活动，是**动作的替代词**。四个字的"理解、识记"背后，其实什么都没有发生。

### 亮点二："给诗重新命名"——用改名反证原名

任务一是这样问的：

> 评一评，下列新的诗题中你认为哪一个最好？为什么？（《**芙蓉思**》《**莲心叹**》《**望乡**》）

而这个任务的前置在**课前**："根据自己对诗歌的理解，为《涉江采芙蓉》**重新命名**。"——学生先自己起一个名字，课上再评教师给的三个名字，**并且"可以尝试与自己的命名进行比较"**。

**这条设计链是完整的：先起名（要理解全诗）→ 再评名（要比较优劣）→ 最后发现原名最好。**

课件第 10 页把落点直接钉出来了——框外两行红字：

> **语言质朴自然**　｜　**表达婉转曲折**

**《芙蓉思》太直，《莲心叹》太露，《望乡》太窄**，三个新题各偏一头，合起来正好说明"《涉江采芙蓉》"这五个字好在哪：**"涉江"是动作（不是"采芙蓉"的地点状语），"采芙蓉"是动作的目的，"芙蓉"又是所遗之物**——一句诗题里三个层次，改一个字就垮。

**这比"请分析标题的作用"高明得多：学生不是解释标题，而是先证明"换个标题不行"。**

### 亮点三："抒情主人公是男是女"，两方立场都写到了具体句子

任务二的问法罕见地精确：

> 有人认为抒情主人公是**男性**，"**涉江**"者和"**还顾**"者**都是男子**；也有人认为抒情主人公是**女性**，"**涉江**"者是**女子**，"**还顾**"者是**男子**，你怎么看？

**两方不是"男/女"两个标签，而是"涉江者"与"还顾者"两个动作的归属分配。** 这就把一场容易变成"我觉得"的争论，变成了一个可以逐句验证的问题：

- 若"涉江""还顾"同属一人 → 全诗是一个男子的独白，"还顾望旧乡"是他回头；
- 若"涉江"属女、"还顾"属男 → 全诗是女子的悬想，"还顾望旧乡"是她想象的他在回头。

**这个分歧一点不虚**，而且它直接决定了后文"悬想"能不能讲通——**只有第二个方案成立，"对写"才有对象。** 教师把这一步放在任务二、把"悬想"放在设计意图里，顺序是对的：**先定主体，才谈手法。**

### 亮点四：与《上邪》对读，比与《子衿》对读更狠

任务三选的对读对象是**汉乐府《上邪》**：

> 学习任务三：比较《涉江采芙蓉》与《上邪》在**诗歌内容和情感表达**上的区别。

这是一步险棋，也是妙棋。《上邪》是：

> 上邪！我欲与君相知，长命无绝衰。山无陵，江水为竭，冬雷震震，夏雨雪，天地合，乃敢与君绝！

**两首诗的差别不是"风格不同"，是"说话的方式根本不同"**：《上邪》把话说尽（五件不可能的事全摆出来），《涉江采芙蓉》什么都不说（采了花，不知道送给谁，回头看不见故乡，最后只说"忧伤以终老"）。**一个是赌咒，一个是沉默。**

**"浅而能深、近而能远"这八个字，只有这样对读才立得住**——"浅"是《涉江采芙蓉》的字面（采花、回头、长路），"深"是它不说出来的部分；而《上邪》恰恰是"深"也说尽了的写法。**用一个"说尽"的文本，照出另一个"不说"的文本。**

### 亮点五：七条推荐资源全在"从对面着笔"这一条线上

任务单第 2 页的七条资源，看上去是杂拌，其实全指向一处：

| 资源 | 关键句 |
|---|---|
| 周邦彦《苏幕遮·燎沉香》 | "**五月渔郎相忆否**？小楫轻舟，**梦入芙蓉浦**。" |
| 王维《九月九日忆山东兄弟》 | "**遥知**兄弟登高处，遍插茱萸少一人。" |
| 白居易《邯郸冬至夜思家》 | "**想得家中夜深坐，还应说着远行人**。" |
| 杜甫《春日忆李白》 | "**渭北春天树，江东日暮云**。" |
| 《庭中有奇树》 | "攀条折其荣，将以遗所思。……**此物何足贵，但感别经时**。" |
| 《迢迢牵牛星》 | "**终日不成章，泣涕零如雨**。……盈盈一水间，脉脉不得语。" |

**六首诗，六种"不说自己说对方"**：王维不说自己想兄弟，说兄弟登高时少了一个人；白居易不说自己想家，说家里人半夜还在念他；杜甫不说自己想李白，说渭北的树与江东的云。**这就是"悬想"的谱系。**

**其中周邦彦那条选得最妙**："梦入芙蓉浦"——**"芙蓉浦"三个字把《涉江采芙蓉》的意象原封不动搬进了宋词**。学生读到这一句，会突然明白"涉江采芙蓉"不是一首诗的事，是一个被反复使用的姿势。

而《庭中有奇树》与《迢迢牵牛星》都是《古诗十九首》里的篇目，**与《涉江采芙蓉》同一组诗**——"遗所思"与"采之欲遗谁"几乎是同一句话的两种说法。

### 亮点六：作业第 2 题给了一篇可以当样板的改写

> 把《涉江采芙蓉》一诗改写成**叙事性散文**，运用想象描摹诗歌的艺术画面，**300 字左右**。

范文里有两处值得记：

> "……**她徒然采摘了象征美好的芙蓉，却难以送给她心上人**。她思念之人，此刻正远在天涯！**正当她独自思夫的时候，她远方的丈夫，也正在此刻无限忧愁，回望着妻子所在的故乡。** 他当然不能望见故乡的山水，也不能望见那在江对岸湖泽中采莲的妻子。此刻展现在他眼前的，无非是漫漫漫长路，和那阻山隔水的浩浩烟云。"

**"正当她独自思夫的时候，他也在回望"——这一句把"对写"讲清了，而且是用叙事的方式讲清的。** 学生写这一段，必须先在脑子里把两个空间并置，否则写不出"与此同时"。

**改写不是"翻译"，是"补空间"**：原诗只有"还顾望旧乡"五个字，范文要补出"他望不见什么"（"不能望见故乡的山水，也不能望见那在江对岸湖泽中采莲的妻子"）。**"不能望见"这四个字是原诗没有的，但它恰恰是原诗的意思。**

### 3.2 好课四特征

**① 理念清晰**：一句话——"**先替这首诗改个名字，再吵清'涉江的人'和'回头的人'是不是同一个，最后拿《上邪》照一照它为什么说得那么少**"。三步都指向同一处：**这首诗的力量在"没说"的那一半。**

**② 思维流畅**：内外两个欣赏方向（"诉诸外部……诉诸内部"）→ 知人论世（沈德潜"不必一人之辞，一时之作"）＋听音频 → 课前自命名 → 评三个新名（芙蓉思／莲心叹／望乡）→ 落点"语言质朴自然／表达婉转曲折"→ 抒情主体之争（涉江者与还顾者的归属）→ 悬想（王维／白居易／杜甫三例）→ 与《上邪》比 → 六个常规方法 → 改写 300 字。

**链条完整，但中段有一处跳**：任务二讨论完"主体是男是女"之后，**没有明确给出结论就转到"悬想"**——设计意图里写"本学习任务关涉到'悬想'手法的分析"，可教案正文里**没有一句是讲"悬想"是什么的**（"悬想"二字只出现在目标 3、重点 3、难点 1、设计意图四处，正文一次都没解释）。**这节课最核心的概念，教案里只有名字，没有讲法。**

**③ 学生主体**：◐。**给分的地方**："学生活动"独立成栏，且任务三写的是"**诵读，小组交流讨论，小组代表发言**"；任务一有课前自命名的前置；作业要"全班课后交流展示，优秀作品张贴在班级宣传栏"——**有展示环节，这在五份资源里只有这一份明写**。**扣分的地方**："理解、识记"与"完成作业"两处是空栏；"悬想"这一核心手法在教案中无一处展开，学生无从"运用想象来描摹"；**任务单两页只有题干与资源，无一处作答留白**。

**④ 实践创新**：✅✅ 两处。**"给诗重新命名"**（先自己起名、再评三个新名、最后反证原名不可换，把"标题作用"这类死题变成了判断）；**与《上邪》对读**（用一个"把话说尽"的文本照出另一个"不说"的文本，"浅而能深"由此立得住）。

### 3.3 四大支柱与素养锚定

| 项 | 判断与依据 |
|---|---|
| 理念为基 | ✅ 一条主线（标题—主体—手法—对读）贯穿七个环节，"内外两个角度"（"诉诸外部……诉诸内部"）在导入处立起，末尾六法收束，前后照应 |
| 目标为纲 | ❌ **本组最弱的一环**：目标以教师为行为主体（"指导学生""引导学生""让学生"）；**重点＝目标复制、难点＝目标 3、4 复制**，三栏无区别；全课**无课时标注**、作业无评分标准 |
| 实施为重 | ◐ 容量偏大：一课时内要做"评三个新名＋主体之争＋悬想三例＋与《上邪》对读＋六法总结"，**教案未标课时**；且"小组交流讨论"只出现在任务三一处，其余五个环节都是"个人发言"或"理解、识记" |
| 个性为魂 | ✅ 三个新题（《芙蓉思》《莲心叹》《望乡》）是教师自己拟的，**每一个都偏一头**（太直、太露、太窄），这种"错得各有道理"的选项设计见功力；"为诗歌命名能体现学生对诗歌的理解程度"一句，也是教师自己的判断 |
| **目标精准可测** | ❌ 四条目标无一可测（"感悟""准确把握""体会""增强文化自信"），重点难点不含任何可观察行为；作业第 1 题（反复诵读体会艺术特点）**答案示例只有一个"略"字**——这一题连教师自己也没法给答案 |
| **思维方法建构** | ✅✅ 三样：**命名比较法**（给同一首诗起不同的名字，用"改名失败"反证原题之妙）、**主体归属法**（把"涉江""还顾"两个动作分派给不同人物，看诗意如何变化）、**对读反衬法**（用《上邪》的"说尽"照出《涉江采芙蓉》的"不说"） |
| **单元整体视角** | ◐ **横向有一条很实的线**：《庭中有奇树》《迢迢牵牛星》与《涉江采芙蓉》同出《古诗十九首》，**三首同组诗并列**，这是本组五份资源中唯一把"组诗"关系摆出来的；但**未提及同单元的《静女》《鹊桥仙》《虞美人》**（资源中未见），也没有把"诵读"接到"古诗词诵读"这一板块的任务上——教案写"吟咏诗韵""播放配乐朗诵音频"，但全课没有一句读法指导 |
| **问题链驱动** | ✅ 感知（哪个新名最好）→ 分析（涉江者与还顾者是不是同一人）→ 评价（与《上邪》比，差别在哪）→ 创造（改写 300 字叙事散文）。**四级俱全，但"评价"这一级只有一问、且没有落成表格或讨论框架** |

### 3.4 需要说出的五处问题

1. **教案第 3 页留着评审批次的模板说明**。表格外一行："**备注：教学设计应至少含教学目标、教学内容、教学过程等三个部分，如有其它内容，可自行补充增加。**"这不是教学内容，是评审模板的填写提示。**同批另一份《静女》（鲍世佳）第 7 页也有同一句**——可见这是同一个批次的通病，不是个别疏漏。

2. **重点四条＝目标四条，难点两条＝目标第 3、4 条，三栏一字不改**。逐字比对：目标 1"通过'知人论世''吟咏诗韵'的诗歌阅读方法，指导学生感悟诗歌表达的思想感情"，重点 1 一字不差；目标 3、4 与难点 1、2 亦一字不差。**结果是"重点"不再是重点（四条全是要点）**，"难点"也不再是难点（等于"后两条目标"）。**一节 40 分钟的课不可能四个重点**，教师真正想抓的"悬想"与"浅而能深"，被埋在四条并列里。

3. **"悬想"这个核心概念，教案正文一次都没有解释**。检索全篇："悬想"出现在目标 3（"引导学生了解'**悬想**'的手法"）、重点 3、难点 1、任务二的设计意图（"本学习任务关涉到'**悬想**'手法的分析"）——**四处都是"要讲"，没有一处是"讲什么"**。而目标 3 的后半句是"并**运用想象来描摹诗歌的艺术画面**"，这是一个动作，学生若不知道"悬想"是什么（从对方着笔、由虚衬实），这个动作做不了。**真正把"悬想"讲清楚的是任务单那七条例证诗，而教案没有把它们组织成"什么是悬想"的说明。**

4. **教案要"播放名家配乐朗诵音频"，页图中找不到这段音频**。第 2 页教师活动栏："**播放名家配乐朗诵音频**，提醒同学留意读音和注释"；学生活动栏："**听音频朗诵，纠正读音**，留意注释"。但四类资源的页图里**没有音频文件、没有链接、没有二维码**（教学设计 3 页、任务单 2 页、作业 1 页**全部读完**，课件 21 页**抽读 6 页**，均未见）。而"吟咏诗韵"是本课目标 1 的方法之一、也是环节（二）的名字——**这一环节的核心材料缺失**。同一课的"浅而能深、近而能远"，教案与课件也**均未标出处**（只有任务单补了"胡应麟《诗薮·内编》卷一"，且夹在目标里，学生未必会读）。

5. **作业第 1 题无法作答，答案示例写"略"**。题面："反复诵读《古诗十九首》，通过诵读进一步体会《古诗十九首》'浅而能深、近而能远'的艺术特点。"——**问题有三**：① 学生手上只有《涉江采芙蓉》一首，其余十八首**未提供**（任务单只给了《庭中有奇树》《迢迢牵牛星》两首，"反复诵读《古诗十九首》"在资源上不成立）；② "体会艺术特点"**没有可交的成果**，无法检查；③ 作业给的答案示例第 1 条只有一个字："（**略**）"。**这是本组五份作业中唯一一处教师自己标"略"的地方**——它等于承认这道题没法评价。

### 3.5 一句话评选理由

> 这是一节让学生在“改名”和“认人”上真做判断的《涉江采芙蓉》课，环节一路顺下来：先由“诉诸外部／诉诸内部”两个欣赏方向导入并交代知人论世，再由学生课前为诗重新命名、课上合评《芙蓉思》《莲心叹》《望乡》三个新题，落到“语言质朴自然／表达婉转曲折”，随后辨析“涉江者”与“还顾者”是否一人，把抒情主体的归属摊成可逐句验证的问题，末了以王维、白居易、杜甫三例带出“悬想”，与《上邪》对读，收在六个常规方法与 300 字改写；最亮的一处正是这步对读，“学习任务三：比较《涉江采芙蓉》与《上邪》在诗歌内容和情感表达上的区别”，用一个把话说尽的文本照出另一个什么都不说的文本，“浅而能深”才立得住；可议之处也硬：教案第 3 页留着“备注：教学设计应至少含教学目标、教学内容、教学过程等三个部分”一行评审批次说明，重点四条与目标四条、难点两条与目标 3、4 一字不改，“悬想”在正文一次未解释、四处只有名字，教案写着“播放名家配乐朗诵音频”而四类资源里没有音频、“浅而能深、近而能远”教案与课件均不标出处，作业第 1 题“反复诵读《古诗十九首》”在资源上不成立、答案示例只有一个“（略）”，另有三份资源均无课例编号与“教学人员”栏、教案四条目标而任务单三条少了“文化传承与理解”、课题栏不带书名号而题干一律带。

## 四、同课异构对照：与陈恺欣《涉江采芙蓉》（同单元另一版）的比较

两版同教一首八句的汉末文人诗，路子完全不同：**张版用"改名—认人—对读"三个追问推进，陈版用"微电影的三次拍摄决定"（视角／场景／景别）推进**。

| 比较项 | **张健筠版（福建师范大学附属中学）** | **陈恺欣版（福建省厦门市翔安中学）** |
|---|---|---|
| **情境** | 无整体情境，只有"（一）课堂导入"的"**情境创设导入**"——实为方法说明（"诉诸外部——探寻诗人的生平和他所处的环境；诉诸内部——品味诗情、感受诗意"） | "校园举办了以'**从诗情画意到情动影生**'为主题的创意活动，将喜爱的诗歌**拍为微电影**……请你完成一份关于**拍摄视角、场景切换、景别选择、主旨立意**等方面的设计方案" |
| **诵读怎么处理** | 靠**音频**："**播放名家配乐朗诵音频**，提醒同学留意读音和注释"；学生"听音频朗诵，纠正读音"。**但页图中未见这段音频**；抽读各页亦无诵读标记 | 靠**字面切分**：课前准备表把原诗按词切好——"**涉江/采/芙蓉，兰泽/多/芳草。采之/欲/遗谁？所思/在/远道。**"——是**词义切分**，不是四言"二二"节拍；另有"遗（**wèi**）：赠送"等注音四条。**无音频、无重音、无升降调** |
| **节奏／韵脚** | **均无** | **节奏有半（词义斜线），韵脚无**（"芙蓉—芳草—远道—浩浩—终老"的换韵未提） |
| **情感层次是否落到操作** | **落到一处**：任务三"诵读，小组交流讨论"，与《上邪》比"情感表达"的区别 | **落到操作**：景别设计里给出"全景+中景+全景+中景"与"全景+中景+全景/中景+全景"两套组合，并把"**由远到近，依次为远景、全景、中景、近景和特写**"作为可执行规则 |
| **教学落点** | **鉴赏＋改写**：评新名／定主体／比《上邪》／改写 300 字叙事散文 | **鉴赏＋设计（创作）**：三套拍摄方案（视角→形象／场景→对写／景别→主旨）／课后"脚本并拍摄"或"宣传词 400 字左右" |
| **目标可测性** | 四条目标全不可测（教师为主体）；作业第 1 题答案"（略）" | 三条目标全不可测（"培养……能力""提高……能力"）；**但任务单三页有大量空白作答区**，作业有学生范文 |
| **最强处** | **"给诗重新命名"**（《芙蓉思》《莲心叹》《望乡》三题各偏一头，反证原名不可换）＋**与《上邪》对读**（用"说尽"照"不说"） | **抒情主体三方案＋括号标说话人**（"(女子)涉江采芙蓉……(男子)还顾望旧乡"）＋**作者／叙述者／抒情主人公三概念区分**＋**甲骨文"涉""采""遗""望"四字表** |
| **最弱处** | 重点是目标的逐字复制；**"悬想"正文一次未解释**；音频缺失 | **作业第 2 页整页只剩一行字**；教案教科书栏"人民教育出版社**出版社**"重复、书名多"**教材**"二字；三张插画无出处 |

**三点具体差别值得单说：**

**其一，关于"抒情主体"这一问，两版都问了，但问法完全不同。** 张版问的是**二选一**："'涉江'者和'还顾'者**都是男子**"还是"'涉江'者是**女子**，'还顾'者是**男子**"——两个立场，一个判准（动作归属）。陈版给的是**三个方案**：女性、男性、**旁观者**（"旁观者以上帝视角处于这幅'采莲图'与'望乡图'中，全知全能地共情着采莲人与漂泊者同心而离居的无奈"）。**张版把问题收紧（两方），陈版把问题放开（三方，且引入"全知视角"）。** 收紧利于课上讨论出结果，放开利于学生理解"视角"这个工具本身——但陈版多出的"旁观者"方案，严格说已不是"诗中人物"，而是"读诗人"，**三案并列在逻辑上不同层**（这一层教案未辨析）。

**其二，关于"对写／悬想"，两版都讲了，但一个给名字不给解释，一个给解释不给练习。** 张版的"悬想"**只出现在目标与设计意图里，正文无一处解释**，学生拿到的只有任务单七条例证诗；陈版则把"**对写法**"做成了完整的三层：定义（"又叫'**对面落笔**'，即明明是主人公对对方有所举动，作者却不直接描述"）＋两家经典（刘熙载"**正面不写写反面，本面不写写对面、旁面，须如睹影知竿乃妙**"、浦起龙"**心已驰神到彼，诗从对面飞来**"）＋一张填好的分析表（典型特征／诗中体现／表达效果三行）。**陈版把"对写"讲透了，张版把"对写"的例证备足了。** 两版的缺口正好互补。

**其三，关于"诵读"，两版都没有真正做。** 张版把诵读外包给一段**不存在的音频**；陈版把诵读化成了**词义斜线**（"涉江/采/芙蓉"），并给了四个注音（"遗 wèi"）。**两版都没有标重音、没有标升降、没有说韵脚**——而"芙蓉—芳草—远道—浩浩—终老"的换韵，恰恰是"浅而能深"之所以"深"的声音根据（前四句押仄声、后四句转平声，情绪由"采"的轻快落到"终老"的沉痛）。**同单元《鹊桥仙》（邓泽源版）在课件第 8、10 两页做到了斜线、红字重音、↗↘升降、破折号延长**，这一板块的"诵读"落差由此更明显（详见《鹊桥仙》研读"单元整体视角"一栏）。

**结论**：两版的互补关系清晰。**张版强在"问题设计"**（给诗改名、主体二选一、与《上邪》对读），**弱在"概念不落地"（悬想只在目标里）与"目标复写目标"**；**陈版强在"概念铺得透、支架做得实"**（三概念区分、对写三家注、景别规则、任务单空白作答区），**弱在"整页残页与著录粗糙"**。**若要互补：把陈版的"对写"定义与三家注搬进张版的"悬想"位置，张版最核心的那个概念才立得住；把张版的"给诗改名"接到陈版任务一之前，陈版三方案的选择才有一个"为什么非要选"的起点。**
