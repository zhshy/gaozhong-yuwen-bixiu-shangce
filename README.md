## 本库有什么

统编版必修上册全部 **79 个课例**，每个课例收录四类原件：

| 类别 | 说明 |
|---|---|
| 教学设计 | 授课教师的完整教案（含目标、重难点、教学流程） |
| 学习任务单 | 随课下发的学习任务单 |
| 作业练习 | 课后习题 |
| 课件 | 授课 PPT |

外加 **79 份《课例研读与评选理由》**，逐课对照吴丹红《好课的标准与评价》框架写成的评审稿。

## 三个按钮怎么用

目录页每行有六个按钮，其中：

- **绿色「查看」** — 在浏览器里直接翻这课的全部页图，分四类页签，随点随看。
- **蓝色文件名** — 下载原 docx / pptx，交给 Word 或 WPS 打开。
- **紫色「研读」** — 读这课的评选理由全文（页内右上角可下载 md 原文）。

原始 docx / pptx 是页图容器，正文文字很少、整页扫描图为实，所以浏览器无法直接渲染，"查看"页是针对这一点专门做的。

## 研读稿的结构

每份研读统一为五节：

1. **四类资源梳理** — 逐类列出内容、页数、可取处与不足
2. **教学设计的思路亮点** — 4–6 条，每条有原件原话为证
3. **对照专家标准的评选理由**
   - 3.1 四维指标表（目标内容 / 教学过程 / 教学资源 / 技术规范）
   - 3.2 好课四特征（理念清晰、思维流畅、学生主体、实践创新）
   - 3.3 四大支柱与素养锚定
   - 3.4 需要说出的问题（落到具体页码、栏位或原句）
   - 3.5 一句话评选理由（单句 450–600 字）
4. **同课异构对照** — 有异构的课才写，如《静女》《涉江采芙蓉》《虞美人》《短歌行》两版

## 本地使用

不必依赖网络。下载仓库后，直接双击 `目录.html` 用系统浏览器打开即可——页内联显示，docx 交给 WPS 打开。

若想在本地起服务：

```bash
cd 本目录
python -m http.server 8765 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8765/目录.html
```

## 来源

全部课例原件来自**国家中小学智慧教育平台 · 国家中小学课程资源（2020 年秋季）**，教材为人民教育出版社《语文》必修上册 2019 年 8 月第 1 版。本库仅作教学研究与备课参考，版权归原平台与授课教师所有。

原另有 11 个 2021 年度「基础教育精品课·部优」课例，因平台仅提供微课视频 / 学习任务单 / 作业练习三类、缺教学设计与课件，未予收录。

## 仓库体积

约 1GB，其中 765MB 为四类资源原件，229MB 为 `_view` 下的压缩页图。这样一个仓库方便一次拿全，若只想 clone 研读稿和网页，用稀疏检出即可：

```bash
git clone --filter=blob:none --sparse https://github.com/zhshy/gaozhong-yuwen-bixiu-shangce.git
cd gaozhong-yuwen-bixiu-shangce
git sparse-checkout set '/第一单元' '/第二单元' ...
```
