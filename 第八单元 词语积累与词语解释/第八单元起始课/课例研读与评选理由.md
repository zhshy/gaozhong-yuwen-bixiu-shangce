| **导入** | "同学们大家好，今天我们共同学习高一必修上第 8 单元——词语积累与词语解释起始课。"<br>**教师提问**："有同学会问，我们小学初中就在不断地学习词语，学字的音、形、义，学组词、解词、造句，学短语、语法和修辞。怎么到了高中还要专门用一个单元来学习词语的积累与词语的解释，有这个必要吗？" |
| **环节一**<br>明确本单元学习的意义、目标与内容 | **教师提问**："不知同学们是否听过这样几句话：学习语文有'**三怕**'：一怕文言文，二怕周树人，三怕写作文。**这三怕的原因是什么**？"<br>**学生回答**："看不懂，想不透，写不出来。"<br>**教师明确**："其实，这'三怕'的**根本原因就在于词语积累、词义理解、语言运用不过关**。"随后分三层说理：缺文言实虚词积累→读不懂文言文；不能准确解读字、词、句、篇→无法真正理解周树人；自己的词语库积累不足→"语言干瘪，拙于表达，词不达意，自然写不出好的作文"。<br>**读单元导语**（教师逐句读、圈画重点）："'说话写文章离不开词语。如同盖房子需要砖石一样，词和短语就是语言表达的"砖石"。我们要做生活中的有心人，平时多读多记，**积累**尽可能丰富的词语，形成自己的词语库。'"<br>"积累是为了**运用**，要让词语库中的词语'**活**'起来，就要**准确理解**词语的含义，能对词语进行比较、辨析，并根据表达的需要，**恰当地选择和使用**。"<br>"本单元围绕词语积累与词语解释开展学习活动。要**了解汉语词语的特点**，通过**多种方式积累词语**；学习**辨析词义的方法**，把握词义变化的规律，认识古今汉语的联系和差异；结合词义特点，探究语言表达中词语选择**的艺术**，提高理解和运用词语的能力。"<br>**教师讲评**："这里把词语比喻为'砖石'非常贴切……只有建筑材料质量过硬，设计运用巧妙，造出的房子才会坚固美观有创意。"<br>另点出核心素养"'**语言的建构与运用**'"以及本单元所属"'**语言积累梳理与探究**'任务群"，"旨在**培养学生丰富语言积累、梳理语言现象的习惯**，在观察、探索语言文字现象，发现语言文字运用问题的过程中，**自主积累语文知识，探究语言文字运用规律，增强语言文字运用的敏感性，提高探究、发现的能力，感受祖国语言文字的独特魅力，增强热爱祖国语言文字的感情**"。<br>**指路**："请同学们迅速浏览教材 P126 的'学习活动'。" |
| **环节二**<br>从单元学习活动中提炼、总结学习方法 | **教师提问**："我们了解了单元目标与内容，那么高中的词语学习与小学初中到底有什么不同呢？我们先看一个问题。"<br>"**如果你说出 20 个描写人的外貌出色的词语，你词语库的库存够吗？**"<br>**学生回答**："这些都是写人外貌的词语。应该先明确词语的意思，然后依据不同的特点分类。**单音词／多音词；褒义词／贬义词／中性词；口语／书面语；描写对象，描写角度，修辞手法……**"<br>**教师总结**："我们的语言太丰富，太有表现力了！想夸一个人长得漂亮，不会只是有'**perfect（完美）beautiful（形容词美丽的）pretty（漂亮的）lovely**'几个词可用，我们有成百上千个词语可供选择。"<br>**教师总结（第二例）**："40 年代有一部美国电影叫《**Bathing Beauty**》，如果直译就是'泳装美女'，电影在中国上映时，中国的译者给它起了一个好听的中文名字《**出水芙蓉**》，既含典雅体现中国人的文化品味，又符合剧中女主角游泳教师的身份，显示了翻译者高超的语言运用能力。"<br>**留给学生的小活动**："收集《诗经》、楚辞、汉乐府里描写美女外貌的词语并作梳理分类，也可以设计一个《**红楼梦**》人物外貌描写词语的专题学习活动。"<br>**"三条要求"**：<br>1. **从积累到建构**——"（积累梳理，要有系统、有计划、有步骤持续的进行。建构语言运用规律和个人语言体系）"<br>2. **从语感到语理**——"（发展语感，把语言现象上升到语言规律，培养语理，发展语言运用的自觉性。）"<br>3. **从零散到结构**——"（将零散的现象、知识整合起来，形成结构化知识）。" |
| **环节二后半**<br>（第 4 页） | **教师提问**："本单元由 3 个学习活动和 7 篇学习资源构成。请同学们按下暂停键，浏览本单元的内容，思考：**本单元的内容有什么特点，我么应该为学习这个单元做哪些准备？今后的语言学习要怎样展开**？"<br>**学生思考一**："复习梳理以往学过的词语知识（汉字的演变、造字法、词义知识、语法、修辞、文言现象、文化知识、文言实虚词等），为单元学习做好准备。（部编版初中教材有较完整的词性、短语、搭配、单句复句、修辞等的知识短文，请做整理）"<br>**学生思考二**："反思自己词语积累、梳理，词义辨析的方法是否正确，学习有效的语言学习方法，及时改进。"<br>**学生思考三**："词语学习贯穿于整个语文学习过程中，存在于生活的方方面面，要有**语境意识**，要有积累、梳理、提炼、整合、固化以及自觉运用的意识。"<br>**教师明确**："我们要**梳理以往的语言知识**，更应该及时调整改进语言积累探究与运用的学习方法。"<br>**八个单元的"词语回访"**（原文连续举例）：<br>· 第二单元《立在地球边上放号》"**号**"是多音字，"到底是放号（四声），还是放号（二声）？"<br>· 《百合花》"他执拗地低着头，**像钉在地上似的**，不肯挪步"中"钉"字的修辞手法和表达效果；<br>· 《诗经·芣苢》"采、有、掇、捋（luo）、袺（jie）、襭（xie）"，"**四个跟手有关，两个跟衣服有关**"；<br>· 第三单元《归园田居》"榆柳荫后檐"，"如果把'荫'换成'种'，一字之差，句子的意思是否有变化？表达效果有什么不同？"<br>· 第四单元《家乡文化生活》"做一个关于家乡方言的调查报告"；<br>· 第五单元《乡土中国》"社会学领域专门词汇的理解以及学术著作的**语体色彩**的体会"；<br>· 第六单元《劝学》《师说》虚词"**而**""**之**""**其**""**焉**"、"**不耻相师**"中"耻"的意动用法、"**爪牙之利，筋骨之强**"的句式特点；《反对党八股》《拿来主义》两篇议论文"语言特点却迥然不同"；<br>· 第七单元散文"'月下的荷塘，荷塘上的月色''清、静、悲凉的故都的秋''地坛剥蚀、淡褪、坍圮、散落的景象'"；《赤壁赋》"**壬戌**"干支纪年法、"**望**""**朔**"的含义等文化常识。<br>**收束**："看来，语言学习确实存在于整个语文学习过程中，每个单元，每个专题，每个活动都离不开语言的学习。" |
| **环节三**<br>任务驱动：在明确学习内容与学习方法的基础上，自主设计学习活动 | **教师提问**："本单元有 3 个大的学习活动需要落实，给大家**五分钟**时间，小组讨论，针对这个单元的学习活动，同学们有哪些实施的具体策略和建议？（**全班共 8 个小组，1、2、3 组讨论第一个学习活动，4、5 讨论第二个活动，6、7、8 组讨论第三个学习活动**）。现在你可按下暂停键。"<br>**（一）了解词语家族，让积累更有效**：1. 小组讨论，设计表格，按类别为词语分配"住房"；2. 小组讨论，提高词语学习的效率方法有哪些？3. 积累梳理交际中常用的谦敬词，给谦敬词分类，梳理这些词语的适用对象和应用情境。<br>**（二）充分利用成语"宝库"**：1. 组织成语竞赛、每日成语接龙、班级（年级）成语大会。2. 按成语的出处分类整理，如：出自《论语》的成语。3. 辨析成语中的多音字、多义词。4. 搜集媒体误用频率较高的成语，分析错误原因。5. 以《成语中的__（酒、竹、棋、玉、年、节气、礼仪……）文化》为题，写一则语言札记。<br>**（三）关注新词语，让语言鲜活生动**：1. 搜集整理新词语，结合单元资源，分类整理，讨论新词语产生的途径。2. 梳理体会新词语中的时代特征，探究新词语中包含的信息，体会其中反映出的社会变化和文化现象。3. 界定新词语的概念，讨论新词语的适用范围和选用标准，保护我们的语言环境。<br>**学习活动二、把握古今词义的联系与区别**：1. 整理初中及必修上文言文中常见虚词的意义和用法，制作**积累卡片**，梳理归纳。2. 阅读"学习资源"中的文章、文段，总结词义引申及词义发展变化的规律。3. 设计表格梳理归纳，总结形声字形旁的表义特性，借助形训，在语境中推断文言词义。<br>**学习活动三、词义的辨析和词语的使用**：1. 结合第七单元的散文，第一、三单元的诗歌、小说，第六单元的议论文，体会文学作品**炼字**的妙处。2. 体会词语的**感情色彩**，把握**语体色彩**，为有问题的通知、广告、启事、邀请函、申请书等**改错**。3. 结合阅读学写批注，随时积累品评好词好句，赏析著名作家（如鲁迅、老舍、沈从文、孙犁、汪曾祺等）的语言风格，**学写语言札记**。<br>**教师评点**："同学们的设计很丰富，有创意，可见大家已经了解了本单元的学习目的及内容，也已经明确了我们要怎样去学习这个单元。" |
| **作业与期望** | 作业：1. **梳理已有的语言知识**。2. **选择一两个学习活动进行专题探究**。<br>"在本单元接下来的学习活动中，希望同学们积极参与，合作交流，在跟随老师学习的同时，不断完善同学们自己设计的活动策略，**及时落笔固化成果**，圆满完成学习任务。并将本单元学到的方法运用到今后的语文学习中去。" |

### 1.3 课后练习（1 页，无题目）

整页只有一张表：课程基本信息（编号"2020QJ10YWTB 057"）＋学生信息（四格空）＋"课后练习"栏内两行字：

## 二、教学设计的思路亮点

### 亮点一：用"三怕"把"还要不要专门学词语"变成一个学生认账的痛点

起始课最难的是回答"这一单元为什么存在"。教案没有从课标讲起，而是先摆一句学生都听过的话：

> 学习语文有"**三怕**"：一怕文言文，二怕周树人，三怕写作文。

再追问"这三怕的原因是什么"，学生答"看不懂，想不透，写不出来"，教师收一句："其实，这'三怕'的**根本原因就在于词语积累、词义理解、语言运用不过关**。"

**这一段的逻辑是"归因"，不是"介绍"。** 它把三件学生原本分属三个单元、三种能力的困难，收束到同一个根上——词语。后面三层解释也照着这三怕排：缺实虚词积累→读不懂文言文；不能准确解读字词句篇→"无法真正理解周树人"；词语库不足→"语言干瘪，拙于表达，词不达意"。**一个开场，替整个单元做了合法性论证。**

### 亮点二：三个"从……到……"把任务群的语言翻译成学生能记住的三句话

环节二末尾，教案给出"高中词语学习与小学初中的不同"：

| 序 | 提炼 | 括注原文 |
|---|---|---|
| 1 | **从积累到建构** | "积累梳理，要有系统、有计划、有步骤持续的进行。建构语言运用规律和个人语言体系" |
| 2 | **从语感到语理** | "发展语感，把语言现象上升到语言规律，培养语理，发展语言运用的自觉性" |
| 3 | **从零散到结构** | "将零散的现象、知识整合起来，形成结构化知识" |

**这三句是全课最经得起推敲的地方。** "从语感到语理"一句尤其准——它解释了为什么高中还要学词语：不是词汇量不够，而是**从"觉得别扭"到"说得出为什么别扭"**。而"从零散到结构"正好对接着本单元的核心工具（词语家族、词义演变图、分类表格）。**三句话都是六个字，学生抄得下、记得住、用得着**——比"培养语言建构与运用素养"这种表述有效得多。

### 亮点三：八个单元的"词语回访"——用学生自己学过的课文证明"词语无处不在"

第 4 至 5 页，教案连续举了**九个已学文本**的例子，每一个都只问一个小问题：

| 已学文本 | 追问 |
|---|---|
| 《立在地球边上放号》（第二单元） | "'号'是多音字，它的读音，到底是放号（四声），还是放号（二声）？" |
| 《百合花》（第三单元） | "'像钉在地上似的'中'钉'字的修辞手法和表达效果" |
| 《诗经·芣苢》（第二单元） | "采、有、掇、捋、袺、襭……**四个跟手有关，两个跟衣服有关**" |
| 《归园田居》（第三单元） | "'荫'换成'种'，一字之差，句子的意思是否有变化？表达效果有什么不同？" |
| 《乡土中国》（第五单元） | "社会学领域专门词汇的理解以及学术著作的语体色彩的体会" |
| 《劝学》《师说》（第六单元） | 虚词"而""之""其""焉"；"不耻相师"中"耻"的意动用法；"爪牙之利，筋骨之强"的句式 |
| 《反对党八股》《拿来主义》（第六单元） | "虽然都是议论性的文章，但二者的语言特点却迥然不同" |
| 第七单元散文 | "'月下的荷塘，荷塘上的月色''清、静、悲凉的故都的秋''地坛剥蚀、淡褪、坍圮、散落的景象'" |
| 《赤壁赋》（第七单元） | "'壬戌'干支纪年法、'望''朔'的含义等文化常识" |

**这不是"举例子"，是"点名"**——学生上一节课刚读过的句子，此刻被重新指认成一个词语问题。《芣苢》那条最典型：六个动词"四个跟手有关，两个跟衣服有关"，**这是把字形、字义、动作还原三件事一次讲通**，也正是本单元后面"词语家族"课会展开的方法。**起始课在这里做了一件很聪明的事：它先给后面每一课埋了一个"钩子"。**

### 亮点四："说出 20 个描写人外貌的词语"——用一次库存盘点制造可感的差距

环节二的问题不是"词语积累重要吗"，而是：

> **如果你说出 20 个描写人的外貌出色的词语，你词语库的库存够吗？**

紧接着教师给了一组英文对照：

> 想夸一个人长得漂亮，不会只是有"perfect（完美）beautiful（形容词美丽的）pretty（漂亮的）lovely"几个词可用，我们有成百上千个词语可供选择。

**这个设计的高明处在于它让人当场"数不出来"。** 学生原答也已摸到方法："先明确词语的意思，然后依据不同的特点分类。单音词／多音词；褒义词／贬义词／中性词；口语／书面语；描写对象，描写角度，修辞手法……"——**分类维度一次给了六个，这就是后面"词语家族"课的雏形**。

《Bathing Beauty》译作"出水芙蓉"的例子也选得好：直译"泳装美女"与"出水芙蓉"的落差，**一眼就能看出"选词"不是修辞的装饰，而是文化的含量**。教师还留了两个可选专题（"收集《诗经》、楚辞、汉乐府里描写美女外貌的词语并作梳理分类""设计一个《红楼梦》人物外貌描写词语的专题学习活动"），**给学有余力的学生留了真实的语料入口**。

### 亮点五：把单元的三个学习活动拆成 17 条可执行的清单，直接当"选题菜单"用

环节三不是让学生"讨论一下怎么学"，而是把三个学习活动逐条铺开，共 17 条具体做法。摘几条最能看出分寸的：

- "小组讨论，**设计表格，按类别为词语分配'住房'**"——"住房"这个比喻让"分类"变得可操作；
- "**积累梳理交际中常用的谦敬词**，给谦敬词分类，梳理这些词语的适用对象和应用情境"——从"谦敬词"入手，是有真实交际价值的切口；
- "搜集**媒体误用频率较高**的成语，分析错误原因"——语料来自真实语用现场，不是练习册；
- "以《**成语中的__（酒、竹、棋、玉、年、节气、礼仪……）文化**》为题，**写一则语言札记**"——给了半开放题式，括号里的七个选项就是七个可自选的方向；
- "为有问题的**通知、广告、启事、邀请函、申请书**等改错"——五种应用文体，正对第四单元"家乡文化生活"的写作任务；
- "赏析著名作家（如**鲁迅、老舍、沈从文、孙犁、汪曾祺**等）的语言风格，学写语言札记"——五位作家，风格差距足够大。

**这 17 条构成了本单元的学习地图**，学生按组认领，后面的课就有了来处。**"及时落笔固化成果"一句也点到了活动单元的要害**：活动课最容易上成"说一说就过去了"，教案明确要求留下东西。

### 亮点六：一句"为词语分配'住房'"，把抽象的"分类"变成能动手的事

清单里最短的一条，也是最像"工具"的一条：

> 小组讨论，设计表格，**按类别为词语分配"住房"**。

"住房"这个词换掉了"归类""分类""类属"三个术语。**学生一听就懂**：一个词要住进哪一间屋？是按语素住（"望"族、"扌"族），按感情住（褒／贬／中），还是按语体住（口语／书面）？**"分配住房"暗含了一个约束——一个词只能有一间主屋**，这恰好逼出"分类标准必须唯一"这条规则，而这正是后面高洁《词语分类——认识词语"家族"》一课的起点（那节课的学生活动一就是两组词：望族、望尘莫及……与提、拉、拽、抓……）。

同一批清单里还有几处同样的"降维"：

- "**搜集媒体误用频率较高的成语**，分析错误原因"——语料从练习册换成了报纸、广告、屏幕；
- "**为有问题的通知、广告、启事、邀请函、申请书等改错**"——五种应用文，改错比改病句更接近真实写作；
- "以《**成语中的__（酒、竹、棋、玉、年、节气、礼仪……）文化**》为题"——一个半开放题式，括号里的七项就是七个可选方向。

**可惜这条最好的条目只写在清单上**：教案没有给"住房"画一张样表，课件也没有。学生讨论五分钟，最后仍停在"设计表格"这四个字上——**"设计"是动词，可这节课里没有一张表被真正设计出来。**

## 三、对照专家标准的评选理由

### 3.1 四维指标

| 维度 | 标准（学生视角） | 本课证据 | 判定 |
|---|---|---|---|
| **目标内容**<br>学生学什么 | 目标科学具体、内容层层递进 | 三条目标呈"认识意义 → 明确内容与方法 → 自主设计活动"的递进，重点（1、2）与难点（3）分置；但**三条主语全是教师**（"教师通过分析单元导语，引导学生认识……""根据本单元教材的特点，引导学生……""在教师的帮助下，学生思考……"），行为动词"认识""体会""明确"**无法观察、无法检测**；单元内容覆盖面极广（汉字、词汇、语法、修辞、语音、语义、语用六个层面），**一节课只能"导览"，不能"落地"**，教案对此并无取舍说明 | 良＋ |
| **教学过程**<br>学生怎么学会 | 是否真正把学生放在中心 | **导入以"三怕"归因起，环节二以"20 个外貌词"制造缺口，环节三以 8 组分工进入具体活动**——三段各有不同的学生动作（答原因／答分类维度／讨论策略）；"学生思考一／二／三"三段并列，是**给学生自己盘点旧知**的设计；但**环节三只有"五分钟"讨论，且 8 个组对 3 个活动，未规定产出形式与汇报方式**，学生讨论完就结束，教师直接给结论（"同学们的设计很丰富，有创意"） | 良＋ |
| **教学资源**<br>我准备了什么 | 资源是否真的支撑学生学 | 资源**类型偏单一**：全部是"讲"的素材——单元导语原文、《现代汉语词典》类数据、八个单元的九个例子、17 条活动清单、两条英文词表；**没有一份可上手的东西**：无词语卡片样张、无词义演变图样例、无辨析札记范文、无表格模板；课件 26 页中仅第 3 页嵌了教材原页图 | 良 |
| **技术规范**<br>学生看得清不清楚 | 呈现是否清楚、稳定 | 版式统一（米白底＋青色方块＋横线＋"高中语文"角标），层级清楚；第 3 页整页嵌教材单元导语实拍图，**学生能看见课本原貌**，这是全课例技术上的最大优点；但**26 页中 20 页以上是纯文字整页**（第 8、14 页各只有一段或四行字），无表格、无图示、无强调色，长段落直接搬自教案，**课堂投影可读性差**；教学设计"时间"栏六页全空 | 良 |

### 3.2 好课四特征

**① 理念清晰**：一句话——"**先让学生承认'三怕'的根在词语，再告诉他们高中的词语学习是'从积累到建构、从语感到语理、从零散到结构'，最后把单元三个活动铺成 17 条让他们自己认领**"。

**② 思维流畅**："三怕"（归因）→ 读单元导语（确立"砖石""积累为了运用"）→ 三条"从……到……"（说清高初差异）→"20 个外貌词"的库存测试（暴露缺口）→ 八个单元的词语回访（证明无处不在）→ 三个"学生思考"（盘点旧知）→ 8 组分工讨论"怎么学"→ 17 条活动清单 → 作业两句 → 结语。**链条完整，且每一环都在回答"为什么学／学什么／怎么学"中的一问**。

**③ 学生主体**：◐。理由是两头热、中间冷：**导入的"三怕"之问、"20 个词"的库存测试、"学生思考一／二／三"的旧知盘点，都是把话筒交给学生**；但**环节一（约两页半）几乎全是教师读导语、教师讲评、教师明确**，学生只有一次"看不懂，想不透，写不出来"的齐答；环节三虽给了五分钟讨论，**却没有规定产出，也没有让组间交流**，教师用一句"很有创意"收束。**学生在这节课里"被问"得多，"做出东西"得少。**

**④ 实践创新**：✅✅ 两处。**一是"三怕归因"**——把单元合法性建立在学生自己的困难上，而不是课标条文上；**二是八个单元的"词语回访"**——用学生刚学过的九个文本（"号"的读音、"钉"的修辞、《芣苢》六动词、《归园田居》"荫"、《赤壁赋》"壬戌"）把"词语无处不在"变成可核对的事实。**"为词语分配'住房'"这个说法也算半处创新**，可惜只出现在清单里，没有做成活动。

### 3.3 四大支柱与素养锚定

| 项 | 判断与依据 |
|---|---|
| 理念为基 | ✅ 两条线互相支撑：一条是"三怕—词语—素养"的**归因线**，一条是"积累—梳理—运用"的**单元线**；且明确点出所属"'语言积累梳理与探究'任务群"与核心素养"'语言的建构与运用'"，**站位准确** |
| 目标为纲 | ❌ 三条目标主语是教师、动词不可测（"认识""体会""明确"），**重点难点直接指向目标序号，等于没有独立的重难点判断**；作业两句也没有对应任何一条目标；全课无评价环节、无评价标准 |
| 实施为重 | ⚠️ 六页教案塞进"三怕＋导语细读＋三条差异＋20 词测试＋八个单元回访＋三个学生思考＋8 组讨论＋17 条清单"，**一课时无法完成**；且"给学生五分钟"讨论三个学习活动，与"1、2、3 组讨论第一个……6、7、8 组讨论第三个"的分工在时间上不匹配（第三组任务最重却只有三组） |
| 个性为魂 | ✅ "三怕"这个切口有教师自己的判断（"根本原因就在于词语积累、词义理解、语言运用不过关"）；《Bathing Beauty》—"出水芙蓉"一例有个人趣味；"为词语分配'住房'"是有体温的比喻 |
| **目标精准可测** | ❌ 四条目标动词（认识／体会／明确／设计）**没有一条能拿出证据**；作业"梳理已有的语言知识""选择一两个学习活动进行专题探究"**无范围、无形式、无字数、无标准**；课后练习页连一道题都没有。**这是本课最弱的一根支柱** |
| **思维方法建构** | ◐ 给了三样：**归因法**（从"三怕"追到词语）、**三维差异框架**（积累／建构、语感／语理、零散／结构）、**分类维度清单**（单音多音、褒贬中、口语书面、对象、角度、修辞）。但**都停留在"说出来"，没有一样被学生用过一遍**——没有一张表被填、没有一个词被真正分类到底 |
| **单元整体视角** | ✅✅ **本批次最强的一份**。它明确"本单元由 3 个学习活动和 7 篇学习资源构成"，把三个活动逐条拆成 17 条；更关键的是**向前回收**——用第二、三、五、六、七单元的九个文本做例证，**向后预留**——"积累卡片""语言札记""谦敬词分类""成语文化札记""为通知广告改错"分别对应后面的"词语家族""古今词义""咬文嚼字""学写札记"几课。**起始课真的起了"起"的作用** |
| **问题链驱动** | ◐ 有三问且层层递进："还有这个必要吗"（价值）→"高中的词语学习与小学初中到底有什么不同"（定位）→"本单元的内容有什么特点，应该做哪些准备"（方法）。但**三问都止于"教师明确"，没有一问要求学生交出成品**；且第三问被"17 条清单"直接覆盖，学生没来得及自己想 |

### 3.4 需要说出的五处问题

1. **三条教学目标的主语是教师，且全部不可测**（教学设计第 1 页"教学目标"栏）。原文三条依次是"**教师通过分析单元导语，引导学生认识**本单元在语文学习中的重要地位""**根据本单元教材的特点，引导学生**进一步认识本单元学习的目标和内容""**在教师的帮助下，学生**思考本单元的学习方法"。**这是"教的活动"而非"学的目标"**；更麻烦的是"认识""体会""明确"三个动词都无法观察——上完这节课，无法判断学生是否"认识了本单元的重要地位"。而"学习重点：学习目标的 1、2""学习难点：学习目标的 3"**只是把序号搬过来，没有说出重难点究竟是什么**。

2. **课后练习页没有一道题，且与教案作业栏逐字重复**（作业练习第 1 页全页）。整页除表头信息外只有两行："1. 梳理已有的语言知识。2. 选择一两个学习活动进行专题探究。"——**"已有的语言知识"指哪些（汉字演变？词性？短语？复句？文言实虚词？），梳理成什么形态（表格？卡片？笔记？思维导图？），交多少，什么时候交，怎么评，全部空白。** 这一页学生拿去无法动笔，教师拿去无法批改。

3. **任务单第 2 页是整页空白模板**。该页只有一个"推荐的学习资源"表框，框内印着"**1.**""**2.**"两个空序号，**其后无任何内容**；页面上再无其他栏目。对照同批次高洁《词语分类——认识词语"家族"》任务单第 2 页，同一栏填了《咬文嚼字》杂志条目（"创刊于 1995 年，由上海文化出版（集团）有限公司主办"），**可见此栏本应填写，本课漏填**——而本单元恰恰是"活动单元"，最需要给学生开资源口子。

4. **三份资源的一致性核对：两处硬伤、六项无碍**。

   | 核对项 | 教案 | 任务单 | 课后练习 | 判定 |
   |---|---|---|---|---|
   | 学期栏 | 秋季 | 秋季 | 秋季 | 一致 |
   | 编号 | 2020QJ10YWTB057（"2020QJ10 ／ YWTB057"两行断开） | 2020QJ10YWTB 057 | 2020QJ10YWTB 057 | 一致，仅换行位置不同 |
   | 课题名写法 | 第八单元起始课 | 第八单元起始课 | 第八单元起始课 | 一致（均不加书名号） |
   | 目标栏名 | "教学目标" | 栏头"**学习目标**"、正文"**教学目标：**" | 无 | **不一致（模板未改净）** |
   | 目标条数 | 3 条 | 3 条，逐字相同 | 无 | 一致 |
   | 教材著录 | 书名＋人民教育出版社＋2019 年 8 月第 1 版 | 同（"2019 年 8 月第 1 版"） | 同 | 一致 |

   另有一处**错字**：任务单第 1 页【学习任务一】"我**么**应该为学习这个单元做哪些准备"，教案第 4 页同一句作"我**们**应该……"。

5. **8 个组对 3 个活动的分配不均，且讨论没有产出形式**（教学设计第 5 页）。原文："**全班共 8 个小组，1、2、3 组讨论第一个学习活动，4、5 讨论第二个活动，6、7、8 组讨论第三个学习活动**"，时间"给大家**五分钟**"。问题有二：一是**第二个活动（把握古今词义）只有 2 个组，第三个活动（词义的辨析和词语的使用）有 3 个组却包含 3 条子任务、涉及"炼字""语体色彩""语言札记"三件不同的事**，负担明显不均；二是**全课没有说每组交出什么**（一张策略清单？一张表格？一个选题？），也没有组间交流环节，教师随后直接进入 17 条标准答案。**五分钟讨论因此更像"暖场"，而不是"设计"。**

### 3.5 一句话评选理由

> 这节课先替整个单元做完合法性论证，再交给学生一张地图：先以“学习语文有‘三怕’：一怕文言文，二怕周树人，三怕写作文”导入，追问原因后收一句“根本原因就在于词语积累、词义理解、语言运用不过关”，再读单元导语抓“砖石”“积累为了运用”并举出“从积累到建构”“从语感到语理”“从零散到结构”，随后用“说出20个描写人外貌的词语”做一次库存盘点、再以九个已学文本作词语回访，末了把三个活动铺成17条清单、八个组五分钟讨论；最亮的是这串回访，《芣苢》六动词“四个跟手有关，两个跟衣服有关”，一句就把字形、字义、动作讲通，也为后面每一课埋了钩子；问题在于三条目标主语全是教师、动词一个都测不了、重难点只是把目标序号搬一遍，课后练习整页只有两句与教案逐字重复的作业、无题无范围无标准，任务单第2页“推荐的学习资源”只印着“1.”“2.”两个空序号、整页空白，任务单栏头作“学习目标”而正文仍作“教学目标：”、“我么应该”一处错字未改，八组对三个活动分工畸轻畸重、五分钟讨论没有规定任何产出；清单本身倒铺得实在，从“按类别为词语分配‘住房’”一直排到“学写语言札记”。

## 四、本课在单元序列中的位置（代同课异构说明）

本课在本批次中**无同课异构**，但它是八课中唯一承担"起"的功能的一节，其后续回收关系可以核到：

| 起始课留下的东西 | 在哪一课被回收 |
|---|---|
| "设计表格，按类别为词语分配'住房'"、"了解词语家族" | 高洁《词语分类——认识词语"家族"》（本课任务单任务二即"列举相应的词语"） |
| "整理初中及必修上文言文中常见虚词……制作积累卡片" | 《古今词义的联系与区别（一）（二）》 |
| "为有问题的通知、广告、启事、邀请函、申请书等改错""体会文学作品炼字的妙处" | 《"咬文嚼字"——词义的辨析和词语的使用》 |
| "写一则语言札记""学写语言札记" | 《做一只语林啄木鸟——学写词语积累、梳理、辨析的札记》 |
| "搜集媒体误用频率较高的成语" | 《"后起之秀"——新词语的词义辨析》 |

**这张表也暴露了一个缺口**：起始课把工具都"说"了一遍（卡片、表格、札记、分类、改错），**却没有一样在起始课上做出样张**。学生带着五个名词进入后续七课，**每个名词都要重新学一遍**——这是"导览式起始课"的通病。
