## 一、四类资源梳理

### 1.1 教学设计（5 页）

| 板块 | 内容 |
|---|---|
| 教学目标 | 通过《无题》与《红烛》的比较阅读，帮助学生**领会"蜡炬""红烛"两个意象在象征内涵与所寄情感上的不同、诗中抒情主人公形象的不同，以及这些不同背后的作者与时代原因** |
| 学习重点 | 通过"**意象解构**"的方式对比，领会两个意象的象征内涵与所寄情感之不同 |
| 学习难点 | 通过"**中年**"与"**青春**"、"**末世**"与"**新生**"的对比，领会差异背后的作者和时代原因 |

**教学流程（七步单链）**

| 环节 | 内容 |
|---|---|
| 一 导入 | 从"意象"概念入手：同一物象被不同情感包裹，会形成不同的意象。举例引出"蜡烛"在李商隐与闻一多笔下的不同——"蜡炬"与"红烛" |
| 二 自读 | 学生自读《红烛》 |
| 三 布置任务 | 讲"**意象解构**"：诗人常把一个完整意象拆成几部分表情达意。**范例**：戴望舒把"丁香"拆成"丁香一样的颜色／芬芳／忧愁"（颜色、味道、气质三部分）。要求找出"蜡炬""红烛"各被拆成哪几部分，并比较象征意义是否相同 |
| 四 学生细读 | 学生暂停播放，自读文本，完成任务 |
| 五 明确＋深度引导 | ① 拆解结果：**蜡炬＝灰＋泪**；**红烛＝色＋灰（蜡）＋泪＋光**——"灰""泪"共有，"色""光"为红烛独有，故从"色""光"入手<br>② 追问：李商隐全诗**未写蜡烛颜色**（生活中可红可白，甚至薛宝钗所说的"绿蜡"），闻一多为何偏选"红烛"？<br>③ 引"红烛啊！这样红的烛！""诗人啊，吐出你的心来比比，可是一般颜色？"——红心之红＝**赤诚、热烈、忠诚**<br>④ 析"光"："是谁点的火——点着灵魂？为何更须烧蜡成灰，然后才放光出？"——照亮别人必先燃烧自己；"烧吧！烧吧！烧破世人的梦……"——照亮别人＝**拯救世人**，燃烧自己＝**自我牺牲**；故"光"象征牺牲自我、拯救世人的理想信念<br>⑤ 对读"灰"与"泪"：蜡炬的灰＝不能承受相思之苦而逐渐残损衰亡的躯体；红烛的灰＝为拯救世人主动牺牲后还能培育花果的脂膏；蜡炬的泪＝相思的悲伤；红烛的泪＝**因理想受到阻碍而产生的着急焦虑**（依据"是残风来侵你的光芒，你烧得不稳时，才着急得流泪"）<br>⑥ 总结：**"蜡炬"＝因不能承受相思之苦而陷入悲伤无法自拔的忠贞；"红烛"＝为拯救世人而主动牺牲自我的理想人格的化身** |
| 六 新任务 | 每节开头"红烛啊！"背后的情绪并不相同，请各用一个词概括九节情绪——赞颂／困惑／了悟／激励／感伤／彻悟／慰藉／认同／肯定和期望；情绪虽有波动，终归困惑感伤让位于肯定期待，**这正是"青春"** |
| 七 归因 | 闻一多写此诗 24 岁，李商隐写《无题》38 岁——**青春 vs 中年**；再列 1923 年六件大事（苏联援助、长沙日军枪杀中国平民、胡适倡研究旧国学、毛泽东创办《新时代》、蔡元培辞北大校长、北大哲学系教授引发爱情问题大讨论）——**新生 vs 末世**。晚唐末世如人生中老年，成熟绚烂却气骨顿衰，李商隐终无法走出"小我"；五四虽动荡而有少年锐气，闻一多遂有献身救世的梦想与力量 |
| 作业 | 请在古今诗歌中找出含有"蜡烛"意象的诗句，思考"蜡烛"意象的象征内涵及其背后蕴含的作者情感 |

### 1.2 学习任务单（2 页）

### 1.3 作业练习（1 页）

仅一条：找出古今诗歌含"蜡烛"意象的诗句，思考其象征内涵与背后情感。与教案"七、作业"、课件 p16 三处一致。

> **观察**：属**同类收集型**作业（再找几个"蜡烛"），与本课核心方法（意象解构）**不构成迁移检测**——学生会找诗，不一定会拆意象。

## 二、教学设计的思路亮点

### 亮点一："意象解构"是方法，不是术语——先给范式，再让学生用

课不从"红烛象征什么"开始，而从"**怎么拆**"开始：借戴望舒把"丁香"拆成颜色／芬芳／忧愁三部分的做法，给出一个**可复制的拆解范式**，再让学生拿它去拆"蜡炬"和"红烛"。抽象的诗学概念，被转成"找出这个意象被分成哪几块"的可操作动作。这正是专家所说"把抽象概念转化为可观察、可操作"在语文学科的落地方式。

### 亮点二：用"交集—差集"给比较阅读定顺序

拆完不是并列罗列，而是做一次集合运算：

```
蜡炬　＝ 灰 ＋ 泪
红烛　＝ 色 ＋ 灰（蜡） ＋ 泪 ＋ 光
        共有：灰、泪　　独有：色、光
```

**先看共有的两项（同中见异），再攻独有的两项（异中见质）**。比较阅读最怕"两首诗有什么不同"这种漫无边际的问法，此处把比较对象压到两个词素上，比较就有了确定的落点和顺序。

### 亮点三："李商隐为什么不写颜色"——用缺席反证选择

追问链是这样的：李商隐全诗**根本没写蜡烛的颜色** → 生活里蜡烛可红可白，甚至可以是薛宝钗说的"**绿蜡**" → 那么闻一多为什么偏偏选"红"？→ "吐出你的心来比比，可是一般颜色" → 红心之红＝赤诚、热烈、忠诚。

**用"没写"来反证"写了"的意义**，是文本细读里很见功力的一步：它把"红"从"描述性词语"变成了"作者的选择"，诗人的用意由此显影。

### 亮点四：同一词素的四向对读

"灰"和"泪"不是分别解释，而是**并置对照**：

| | "蜡炬" | "红烛" |
|---|---|---|
| 灰 | 不能承受相思之苦而逐渐残损衰亡的**躯体** | 为拯救世人主动牺牲后还能**培育花果的脂膏** |
| 泪 | 相思的**悲伤** | 理想受阻而产生的**着急焦虑**（"是残风来侵你的光芒，你烧得不稳时，才着急得流泪"） |

同一个字，一个是"被消耗掉的自己"，一个是"能滋养他者的自己"。落点因此不是"两个意象不同"，而是"**两种人格结构不同**"：忠贞 vs 理想人格的化身。

### 亮点五：九节情绪的"一词概括"，把抒情诗读成一条曲线

九个"红烛啊！"的呼告被逐个拆开，每节只准用一个词——赞颂／困惑／了悟／激励／感伤／彻悟／慰藉／认同／肯定和期望。九个词连起来是一条**波动曲线**，而曲线的走向是"困惑感伤终让位于肯定期待"。**这正是"青春"**——不是结论先行，而是从情绪序列里读出来的判断。

### 亮点六：年龄与时代双坐标，给"差异"两条可检验的线索

- **年龄**：24 岁（闻一多）vs 38 岁（李商隐）——青春 vs 中年；
- **时代**：1923（五四之后天翻地覆的一年）vs 晚唐末世——新生 vs 末世；并列出六件 1923 年大事作实证。

晚唐"像人生的中老年，成熟绚烂，却气骨顿衰"，李商隐终未走出"小我"；五四"虽变革动荡，但有着少年的锐气"，闻一多遂有献身的梦想与力量。**归因给了两条可查证的线索，不是"时代不同"一句空话**。

## 三、对照专家标准的评选理由

### 3.1 四维指标

| 维度 | 标准（学生视角） | 本课证据 | 判定 |
|---|---|---|---|
| **目标内容**<br>学生学什么 | 目标科学具体、内容层层递进 | 目标呈"意象→形象→原因"三级递进；重点（解构对比）与难点（归因）分设且指向不同层级，**不重复** | 良 |
| **教学过程**<br>学生怎么学会 | 是否真正把学生放在中心 | 方法有创新（解构＋交集差集＋缺席反证）；但**七步全程由教师"明确"推进**，学生活动只有"自读—细读—答题"，九节情绪九个词由教师一次给足 | 良− |
| **教学资源**<br>我准备了什么 | 资源是否真的支撑学生学 | 两首诗全文、戴望舒"丁香"范例、薛宝钗"绿蜡"反证、1923 年六件大事、两本诗集推荐——**互文密度高，且每条都用在关键处**（尤其"绿蜡"） | 优 |
| **技术规范**<br>学生看得清不清楚 | 呈现是否清楚、稳定 | 字号足、留白多、单页信息量小，线上可读性好；但多为纯文字结论页，**缺"意象解构"结构化图示**，p13 只列五节、其余靠口述 | 良 |

### 3.2 好课四特征

**① 理念清晰**：全课一句话可概括——"**同一个物象，被不同情感包裹就成了不同意象**"。七步没有一步偏离这条主线，导入即立此命题，作业还回到"蜡烛"这个物象上收口。

**② 思维流畅**：这是本课最强项。**解构 → 交集/差集 → 攻独有项 → 缺席反证 → 同素对读 → 情绪曲线 → 双坐标归因**，七步是一条单链，每步都是上一步的必然产物，中途无回环无重复。

**③ 学生主体**：◐。任务设计本身是"学生做"的（拆意象、找分块、概括情绪），但**答案全部预先写在教案里**，且九节情绪的九个词完全由教师给出——学生即使想出别的词，也会被"教师明确"覆盖。这正落在专家提醒的"教师讲述过多、学生思考时间太少"上。

**④ 实践创新**：两处真创新——"**意象解构**"作为可迁移的操作范式；"**颜色缺席反证选择**"作为细读动作。二者都不常见，且都能被别的课借用。

### 3.3 四大支柱与素养锚定

| 项 | 判断与依据 |
|---|---|
| 理念为基 | ✅ "意象—象征—抒情主人公"三个课标关键词都落到了操作层面 |
| 目标为纲 | ◐ 主线极清晰、任务可达成；**"可评"缺位**——任务单无评价量规，学生不知写到什么程度算好 |
| 实施为重 | ✅ 五页教案对应十六页课件，节奏干净，无冗余环节 |
| 个性为魂 | ✅ 讲"灰"的两副面孔、"残风"二字的分量，能听出教师本人的体认 |
| **目标精准可测** | ⚠️ 未达成。目标动词仍是"**领会**"（领会象征内涵、领会差异背后原因），且主语是"帮助学生"，不是学生 |
| **思维方法建构** | ✅✅ 达成度高。"意象解构"是真正可迁移的方法，学生离课后可拿去拆"柳""月""雁" |
| **单元整体视角** | ◐ 与《沁园春·长沙》未发生关联，单元"青春的价值"只在末尾以"青春"一词点到，**未与单元其他篇目编织** |
| **问题链驱动** | ✅ 感知（拆出哪几块）→ 分析（为何独选红）→ 迁移（换一首含蜡烛的诗）三级完整，唯"迁移"落在了作业而未在课上完成 |

### 3.4 需要说出的问题

1. **目标不可测**：教案"教学目标"栏原句为"通过《无题》与《红烛》的比较阅读，**帮助学生**领会……"，动词是"领会"、主语是"帮助学生"，不是学生的可观测行为；学习任务单"学习目标"栏注明"与教案同一条，未拆分"，两份文件都没有一条行为标准。
2. **可评缺位**：学习任务单 2 页、课后练习 1 页均无评价量规与评分栏，学生拆完"意象分块"、写完九节情绪的一个词，不知道写到什么程度算好（3.3"目标为纲"栏已判"任务单无评价量规，学生不知写到什么程度算好"）。
3. **方法没有留下图形**：16 页课件全片未出现"意象解构"的框架图，学生难以把方法带走；p13 只列"赞颂／困惑／了悟／激励／感伤"前五节，后四节（彻悟／慰藉／认同／肯定和期望）未上屏，只能靠口述。
4. **结论由教师一次给足**："五 明确＋深度引导"一步之内塞进拆解结果、追问、引文、析"光"、对读"灰""泪"、总结六件事；"六 新任务"的九个情绪词（赞颂／困惑／了悟／激励／感伤／彻悟／慰藉／认同／肯定和期望）亦由教师一次给出，学生活动只剩"自读—细读—答题"。
5. **迁移未闭环**：课后练习 1 页仅"找出古今诗歌中含'蜡烛'意象的诗句"一条，属同类收集，与本课核心方法"意象解构"不构成迁移检测——学生会找诗，不一定会拆意象。

### 3.5 一句话评选理由

> 这是一节**以"意象解构"为手术刀的比较阅读课**：先借戴望舒把"丁香"拆成颜色／芬芳／忧愁的范例给出一套可复制的拆解范式，再让学生把"蜡炬"拆成灰与泪、"红烛"拆成色灰泪光，用交集锁定"灰""泪"的共有、用差集逼出"色""光"的独有，又由"李商隐全诗未写蜡烛颜色"反证"闻一多为何偏选红"，落到"红心之红＝赤诚、热烈、忠诚"，最后以 24 岁与 38 岁、1923 年六件大事与晚唐末世两条坐标解释两个抒情主人公的分野，让"青春"从九节情绪的曲线里自己长出来，而不是在结尾贴上去——**方法清晰、证据链完整，是"教方法"而非"教结论"的一次较成功尝试**；可议之处同样具体：教案"教学目标"栏原文作"帮助学生领会"，动词不可测，任务单"学习目标"栏"与教案同一条，未拆分"，两份文件都没有评价量规，"五 明确＋深度引导"一步内塞进拆解、追问、引文、析"光"、对读、总结六件事，"六 新任务"的九个情绪词由教师一次给足，学生活动只剩"自读—细读—答题"，16 页课件无一幅"意象解构"框架图，p13 只列前五节情绪、后四节靠口述，课后练习又只做"再找几首含蜡烛的诗"的同类收集，没有用解构法处理一首新诗，**方法终究没有完成迁移闭环**。
